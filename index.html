Conecta con BD_VITILLA en Google Sheets
Pasos para conectar Google Sheets BD_VITILLA:
1. Abre BD_VITILLA en Google Sheets
2. Extensiones → Apps Script → pega el archivo .gs descargado
3. En el .gs reemplaza SHEET_ID con el ID de tu hoja
   El ID está en la URL: docs.google.com/spreadsheets/d/ID/edit
4. Implementar → Nueva implementación → Tipo: Aplicación web
5. Ejecutar como: Yo · Quién accede: Cualquier persona
6. Clic en Implementar, copia la URL y pégala abajo
La URL termina en /exec
